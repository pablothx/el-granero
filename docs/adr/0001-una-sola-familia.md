# Una sola familia por instalación

El Granero lo usa una única familia: el despliegue es privado y todos los datos le pertenecen a ella, así que no hay separación de datos entre familias ni alta de familias nuevas. Se eligió por simplicidad frente a soportar varias familias con un código cada una. Si en el futuro se quisiera ofrecer la app a otras familias, habría que agregar la pertenencia a familia en cada tabla y en cada consulta.
