# Etiquetas de triaje

Las skills hablan en términos de cinco roles de triaje canónicos. Este archivo asigna cada rol a la etiqueta concreta que se usa en el gestor de issues de este repo.

| Etiqueta en mattpocock/skills | Etiqueta en nuestro gestor | Significado                                         |
| ----------------------------- | -------------------------- | --------------------------------------------------- |
| `needs-triage`                | `needs-triage`             | El responsable tiene que evaluar esta issue         |
| `needs-info`                  | `needs-info`               | Esperando más información de quien la reportó       |
| `ready-for-agent`             | `ready-for-agent`          | Totalmente especificada, lista para un agente (AFK) |
| `ready-for-human`             | `ready-for-human`          | Requiere implementación humana                      |
| `wontfix`                     | `wontfix`                  | No se va a abordar                                  |

Cuando una skill menciona un rol (p. ej. "aplicar la etiqueta de triaje lista para agente"), usar la etiqueta correspondiente de esta tabla.

Editar la columna "Etiqueta en nuestro gestor" para que coincida con el vocabulario que realmente se use.
